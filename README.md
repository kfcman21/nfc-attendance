# NFC 에듀태그 (NFC EduTag)
**- 스마트 학급 & 지능형 과학실 올인원 솔루션 -**

NFC 카드를 태그해 학생 출결, 감정, 독서, 체육, 포인트(화폐), 그리고 **지능형 과학실 탐구 스테이션 & 교구 안전 관리**까지 한 번에 운영하는 **데스크톱 앱(Electron)** 입니다.
인터넷 없이 PC 한 대에서 동작하며, 데이터는 **SQLite**로 로컬에 안전하게 저장됩니다.

- **`npm start`** 하면 데스크톱 창이 자동으로 뜸 (브라우저 따로 열 필요 없음)
- 카드를 대면 실시간으로 출석·점수가 기록되고 대시보드로 한눈에 확인
- **지능형 과학실 탐구 패스포트 & 스마트 교구/시약 안전 관리(MSDS) 지원**
- 모든 자료를 **엑셀(CSV)** 로 내보내거나 **전체 백업(.db)** 가능
- (선택) **구글 시트 동기화**, **공휴일·미세먼지·날씨** 공공데이터 연동, **NEIS 급식·학사일정** 연동

> 구조: Electron 창이 화면을 표시하고, 리더기/DB는 내부적으로 작은 Node 서버
> (`src/server.mjs`)가 담당합니다. 사용자는 `npm start` 만 하면 됩니다.

## ✨ 주요 기능

| 기능 | 설명 |
|---|---|
| **번호별 등록** | 개인정보(이름) 없이 **출석번호만으로** 카드 등록 가능. "번호 빠른 등록"으로 카드만 연속 태그하면 번호 자동 증가 |
| **정시/지각 점수** | 정해진 **마감시각** 이전 태그 = 만점, 이후 = 지각(0점). 설정에서 시각·만점 조정 |
| **대시보드** | 출석/미출석·출석률·정시/지각·오늘 점수·최근 7일 추이·감정 분포 |
| **주간 점수** | 학생 × 요일 점수표, 주 이동, 엑셀 내보내기 |
| **지능형 과학실** | • **스마트 탐구 패스포트**: 스테이션별 태깅 및 탐구 미션 스탬프 랠리<br>• **스마트 교구 & 시약 안전 지킴이**: NFC 원터치 대여/반납 및 MSDS 안전 수칙 팝업<br>• **환경 데이터 비교**: 공공 API(기상/미세먼지) vs 실내 MBL 센서 수치 비교 |
| **감정 출석부** | 태그 후 오늘 기분 선택, 감정 분포 시각화 및 AI 응원 피드백 |
| **지구 포인트 상점** | 1인 1역할 및 환경 실천 포인트 적립, 학급 쿠폰 교환(학급 화폐 실습) |
| **도서 대여 관리** | NFC 학급문고 원터치 대여/반납 및 독서 마라톤 챌린지 |
| **체육 활동** | 셔틀런(왕복달리기) 랩타임 자동 측정, 서킷 트레이닝 스테이션 운동 측정 |
| **데이터 관리** | 전체 백업(.db)·항목별 엑셀(CSV) 저장·항목별/전체 초기화 |
| **두 가지 리더기** | 시리얼(CR-100)과 **HID(키보드형)** 리더기 모두 지원 |
| **공공데이터 연동** | 공휴일 자동 반영, 미세먼지·날씨 위젯(체육 야외활동 판단) (선택) |
| **NEIS 학교 연동** | 오늘 급식·알레르기 표시, 학사일정(휴업일·방학)을 결석에서 자동 제외 (선택) |

## 🚀 실행 / 빌드

```bash
npm install         # 최초 1회
npm start           # 데스크톱 앱 실행 (창 자동 표시)

npm run dist        # 배포용 .exe (설치본 + 포터블) 생성 → dist/
npm run icon        # 로고(build/logo.svg)로 아이콘 다시 굽기
```

- 결과물(`dist/`): **`NFC에듀태그-<버전>-설치.exe`**(설치형), **`NFC에듀태그-<버전>-portable.exe`**(무설치)
- ✅ **완전 독립형** — 대상 PC에 Node.js 설치 불필요(Electron 내장 Node로 구동, serialport는 프리빌트)
- 데이터 저장 위치(배포 실행 시): **`%AppData%\nfc-attendance\attendance.db`** — 업데이트해도 보존
- 하드웨어 없이 시험: 화면 아래 **"테스트: 가짜 카드 태그"** 버튼

## 🖥 화면(탭)별 사용법

- **실시간 출석** — 카드를 대면 **① 출석·점수 → ② 오늘 기분(감정 체크) → ③ 「오늘은 이런 날!」(급식·학사일정·날씨·미세먼지)** 순으로 안내.
- **대시보드** — 그 날 출석/미출석·출석률·정시/지각·획득 점수·7일 추이.
- **📅 주간 점수** — 학생×요일 점수표(정시=만점, 지각/결석=0). 주 이동·**엑셀 내보내기**.
- **🔬 지능형 과학실** — 탐구 패스포트 스탬프 랠리, 스마트 교구 대여/반납 및 MSDS 안전수칙 확인, 실내외 환경 센서 비교 탐구.
- **학생 관리** — 카드 UID 칸을 클릭하고 카드를 태그하면 자동 입력. 번호만으로도 등록 가능.
- **출석 현황** — 날짜별 출석 조회 + CSV(엑셀) 내보내기.
- **💾 데이터 관리** — 전체 백업(.db)·항목별 엑셀(출석/주간/감정/포인트/도서/체육/과학실) 저장·초기화.
- **⚙ 설정·진단** — 점수 마감시각, HID 입력, 구글 시트, 공공데이터, NEIS, 리더기 포트 설정.

## 💾 데이터 백업 / 초기화

**데이터 관리** 탭:
- **전체 백업(.db)** — 모든 데이터를 파일 하나로 내려받기. 복원은 그 파일을 데이터 폴더의 `attendance.db`에 덮어쓰기.
- **항목별 엑셀 저장** — 출석·주간·감정·포인트·도서·체육·**지능형 과학실**.
- **초기화(되돌릴 수 없음)** — 항목별(출석/감정/포인트/도서/체육/과학실) · 전체 활동기록(등록은 유지) · 공장 초기화(전부 삭제).
