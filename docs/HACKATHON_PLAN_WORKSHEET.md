# [2026 기업 연계 정보교원 역량강화 프로젝트] 해커톤 팀 활동 기획서
**프로젝트명: NFC 에듀태그 (NFC EduTag) - 스마트 학급 & 지능형 과학실 올인원 솔루션**

---

## 1. 문제 찾기

### 1. 문제 정의 (누구의 어떤 페인포인트인지)
- **대상**: 초·중등 담임교사, 과학 정보부장 교사, 그리고 초등학생
- **페인포인트(Pain Point)**:
  1. **출결·생활지도의 번거로움**: 매일 아침 수작업 출석 체크, 지각생 파악, 학생들의 정서·기분 상태를 일일이 파악하기 어려움.
  2. **지능형 과학실 탐구 활동 및 교구 관리의 어려움**: 과학실 탐구 스테이션(MBL, 현미경, 관찰 등) 활동 시 학생별 탐구 이력 관리가 어렵고, 고가 교구 및 시약(MSDS) 대여/반납과 안전 관리에 과도한 행정력 소모.
  3. **학급 운영 도구의 파편화**: 출석부, 독서 대여, PAPS 체육 측정, 학급 화폐/포인트 관리가 각각 별도 프로그램이나 종이로 분절되어 교사의 업무 피로도 증가.

---

### 2. 지금 방식 (지금은 어떻게 하고 있는지 · 불편한 점)
- **출결 및 아침 맞이**: 종이 출석부나 나이스(NEIS) 수동 입력에 의존하며, 학생의 등교 시간 및 지각 여부를 직관적인 데이터로 관리하기 어려움.
- **과학실 탐구 및 교구 관리**: 종이 탐구 활동지에 도장을 찍어주거나 수기 장부로 교구를 대여/반납하여 분실 위험이 크고, 실험 안전수칙(MSDS) 안내가 형식에 그침.
- **체육(PAPS) 및 독서**: 셔틀런이나 서킷 트레이닝 시 초시계를 들고 수동으로 기록하거나 종이 독서 통장에 기록하여 데이터 누적 및 성장 분석이 불가능함.
- **불편한 점**: 인터넷이 불안정한 환경에서 클라우드 기반 웹앱은 접속이 끊기며, 학생 개인정보(이름, 사진) 유출 우려가 상존함.

---

### 3. 사용자 (누가 · 어떤 상황에서 쓰는지)
- **주 사용자 1 (초·중등 교사)**:
  - 아침 교실에서 학생 등교 출석 및 감정(마음 날씨) 체크인을 진행할 때
  - 지능형 과학실에서 스테이션 탐구 수업을 운영하고 교구/시약 안전을 통제할 때
  - 체육 시간에 셔틀런/서킷 트레이닝 체력 측정을 자동화할 때
  - 학급 문고 대여 및 1인 1역할 학급 화폐(지구 포인트)를 정산할 때
- **주 사용자 2 (학생)**:
  - 등교 시, 과학실 스테이션 이동 시, 교구 대여 시, 도서 대여 시 본인의 **NFC 학생 카드**를 리더기에 '톡' 태그할 때

## 2. 기능과 자료

### 4. 필요 기능 (핵심 기능 위주 · 한 줄에 하나)
- [x] **NFC 원터치 정시 출석 및 점수제**: 정해진 마감시각 이전 태그 시 출석 점수 자동 부여 및 대시보드 시각화
- [x] **Upstage Solar AI 마음 날씨 감정 출석부**: 출석 후 기분 선택 시 초거대 AI가 맞춤형 긍정 응원 메시지 실시간 생성
- [x] **스마트 과학 탐구 패스포트 (Station Learning)**: 과학실 코너별 NFC 태깅 시 탐구 미션 스탬프 랠리 자동 완주
- [x] **스마트 교구 & 시약 안전 지킴이**: 고가 교구/시약 NFC 대여·반납 및 물질안전보건자료(MSDS) 실시간 팝업 안내
- [x] **📡 SciBit (마이크로비트 MBL 연계)**: micro:bit v2 온습도·조도·소음·가속도 센서 실시간 수집 및 패스포트 기록
- [x] **🤖 SciBot (햄스터 피지컬 AI 탐사 연계)**: 햄스터 로봇 온실 순찰 & 자율주행 탐사 미션 출동 및 완수 스탬프 발급
- [x] **스마트 PAPS 셔틀런 & 체력 성장 그래프**: 반환점 NFC 태깅으로 랩타임 자동 측정 및 Upstage AI 체력 코칭
- [x] **손바닥 NFC 도서관 & 지구 포인트 상점**: 학급문고 원터치 대여 및 1인 1역할 보상 학급 화폐 경제 실습
- [x] **공공데이터 & 100% 로컬 보안**: 실시간 기상청/미세먼지/급식 연동 및 인터넷 없는 완전 오프라인 SQLite 암호화 보관

---

### 5. 입력 자료 (넣을 자료 · 데이터 · 예시 문서)
- **학생 명단 데이터**: 학생 번호, 이름(선택 사항 - 번호만으로 운영 가능), NFC 카드 고유 UID
- **과학실 탐구 및 교구 데이터**: 탐구 스테이션 카드 UID, 교구/시약 카드 UID, 보관 위치, MSDS 안전 수칙 텍스트
- **센서 및 측정 데이터**: 마이크로비트 MBL 센서 수치(온도, 조도, 소음, 가속도), 셔틀런 랩타임 기록
- **공공 API 데이터**: 기상청 단기예보, 한국환경공단 에어코리아 대기질(PM10/PM2.5), NEIS 급식/학사일정
- **AI 프롬프트/키 데이터**: Upstage Solar API Key (AES-256-GCM 암호화 보관)

### 7. 사용 도구 (쓸 도구 이름)
- **프론트엔드/백엔드**: Node.js, Express, Vanilla JS, HTML5, CSS3 (진한 굴림체 가독성 테마)
- **데스크톱 패키징**: Electron, electron-builder (윈도우 설치형 및 단일 포터블 .exe)
- **데이터베이스/보안**: SQLite3 (로컬 독립형 DB), Node Crypto (AES-256-GCM 암호화)
- **하드웨어 연동**: SerialPort (CR-100 시리얼 리더기 및 USB HID 키보드 모드 지원)
- **초거대 AI LLM**: Upstage Solar Pro / Solar Mini API
- **외부 연계 플랫폼**: `kfcman.link/scibit` (마이크로비트 MBL), `kfcman.link/scibot` (햄스터로봇 AI)

## 3. 동작 흐름

### 8. 동작 흐름 (단계별 내용 · 글 또는 그림)

```
┌────────────────────────────────┐       ┌────────────────────────────────┐       ┌────────────────────────────────┐
│          1. 입 력 (Input)       │       │         2. 처 리 (Process)      │       │         3. 결 과 (Output)       │
├────────────────────────────────┤       ├────────────────────────────────┤       ├────────────────────────────────┤
│ • NFC 카드 태그                │       │ • NFC UID 파싱 및 상태 판별    │       │ • 대형 화면 실시간 출석/점수  │
│   (학생 카드 / 스테이션 카드 / │ ───►  │   (출석 / 과학실 / 도서 / 체육) │ ───►  │ • Solar AI 감정 응원 팝업      │
│    교구 카드 / 도서 카드)      │       │ • SQLite 로컬 DB 트랜잭션 기록 │       │ • 탐구 패스포트 스탬프 찍힘    │
│ • 마이크로비트 MBL 센서 측정값 │       │ • Upstage Solar AI 프롬프트 분석│       │ • 교구 대여/반납 & MSDS 안내   │
│ • 햄스터 로봇 탐사 출동 트리거 │       │ • Server-Sent Events 브로드캐스트│      │ • 엑셀(CSV) 내보내기 & 리포트 │
└────────────────────────────────┘       └────────────────────────────────┘       └────────────────────────────────┘
```

- **상세 처리 단계**:
  1. **입력 단계**: 학생 또는 교사가 NFC 카드를 리더기에 접촉하거나, 마이크로비트 센서/공공데이터 값을 전송합니다.
  2. **처리 단계**: 내부 Node 서버(`src/server.mjs`)가 활성화된 모드(`attendance`, `science`, `lending`, `shuttle`)에 맞춰 카드를 식별하고, SQLite DB 갱신 및 Solar AI 피드백을 실시간 생성합니다.
  3. **결과 단계**: 프론트엔드 화면에 진한 굴림체로 대시보드, 패스포트 스탬프(💮), AI 격려 메시지, 교구 대여 현황이 즉시 렌더링되며 모든 데이터는 CSV 엑셀로 백업 가능합니다.

### 9. 멘토 질문 (막힌 것 · 멘토에게 물어볼 것)
- **Q1**: 학교 컴퓨터실/교실마다 OS 환경(Windows 10/11)과 시리얼 포트 COM 번호가 다른데, 시리얼 포트 자동 탐지(Auto-detect) 및 USB HID 키보드 모드 겸용 구조가 안정적인지 점검받고 싶습니다.
- **Q2**: 지능형 과학실의 마이크로비트(SciBit) 및 햄스터 로봇(SciBot) 데이터를 브라우저의 Web Serial/Web Bluetooth API로 다이렉트 연동할 때의 브라우저 보안 정책 고려사항이 궁금합니다.
- **Q3**: 초거대 AI(Upstage Solar) 호출 시 교실 내 인터넷이 일시적으로 끊겼을 때를 대비한 오프라인 룰베이스 피드백 폴백(Fallback) 처리 설계가 적절한지 자문을 구하고 싶습니다.

### 13. 완성 기준 (이것이 되면 완성)
1. **[필수] 완전 독립형 배포**: 인터넷이나 별도 서버 설치 없이 학교 PC에서 `NFC에듀태그.exe` 더블 클릭만으로 100% 정상 작동할 것.
2. **[필수] NFC 올인원 다중 모드**: 학생 카드 태그 시 출석/감정 체크, 과학실 패스포트 스탬프 발급, 교구 대여/반납, 셔틀런 기록이 오차 없이 1초 내에 처리될 것.
3. **[필수] 지능형 과학실 융합**: `kfcman.link/scibit` 마이크로비트 MBL 센서 수집 및 `kfcman.link/scibot` 햄스터 로봇 탐사 미션이 패스포트에 정상 연동될 것.
4. **[필수] 초거대 AI 및 보안**: Upstage Solar LLM 맞춤 피드백이 실시간 생성되고, API 키와 학생 정보가 AES-256으로 로컬에 안전하게 암호화 보관될 것.
5. **[필수] 교사용 데이터 관리**: 모든 활동 기록이 클릭 한 번으로 엑셀(CSV)로 즉시 다운로드되고 전체 백업/복원이 가능할 것.
