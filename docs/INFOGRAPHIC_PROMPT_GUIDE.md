## 5. 🤖 업스테이지(Upstage) Solar AI 연동 및 설정 안내

### 1) 주요 기능
- **마음 날씨 감정 체크인**: 학생이 출석 후 기분을 선택하면 **Solar Pro / Solar Mini** 모델이 학생의 이름을 부르며 따뜻하고 긍정적인 맞춤형 피드백을 실시간 생성합니다.
- **AI 체력 성장 피드백**: 셔틀런 및 서킷 트레이닝 측정 기록을 분석하여 학생의 이전 기록 대비 성장 포인트를 칭찬하는 코칭 리포트를 즉시 작성합니다.
- **강력한 개인정보 보안**: 학생의 개인정보(이름, 번호)와 API 키는 외부로 유출되지 않도록 **AES-256-GCM** 암호화 알고리즘으로 안전하게 로컬에만 저장됩니다.

### 2) 설정 방법
1. [Upstage Console](https://console.upstage.ai/)에서 API Key를 발급받습니다.
2. 프로그램 내 **`⚙️ 설정·진단`** 탭의 **"🤖 업스테이지(Upstage) Solar AI 피드백"** 섹션으로 이동합니다.
3. API 키를 입력하고 **[저장]** 및 **[연결 테스트]** 버튼을 누르면 즉시 모든 AI 기능이 활성화됩니다.
