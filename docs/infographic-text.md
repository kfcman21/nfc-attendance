# 인포그래픽용 텍스트 — NFC 스마트 학급 시스템

## 🏷️ 메인 타이틀
**"카드 한 장으로 열리는 우리 반 하루"**
NFC 스마트 학급 올인원 시스템 (CR-100 출석 프로그램)

부제: 출석 · 감정 · 독서 · 체육 · 환경 포인트를 카드 태그 하나로

---

## 1️⃣ 아침 출석 (핵심 기능)
- 등교하며 NFC 카드를 **삑!** — 자동으로 출석 기록
- 마감 시각(기본 09:00) 전이면 **정시 +10점**, 이후는 지각 0점
- 같은 카드 연속 태그는 자동 무시(중복 방지)
- 출석 직후 **오늘의 기분(감정)** 선택 → 감정출석부 완성
- 오늘의 급식·학사일정·날씨·미세먼지를 한 화면에서 안내

## 2️⃣ 감정출석부 & AI 응원
- 6가지 감정(😄🙂😐😫😢😡)으로 매일 마음 체크
- 반 전체 "감정 날씨" 자동 진단 (☀️ 아주 맑음 ~ ⛈️ 폭풍우)
- 부정 감정이 잦은 학생을 조용히 알려줘 **선생님의 관심 유도**
- Upstage Solar AI가 학생 개인에게 **즉석 응원 메시지** 생성

## 3️⃣ 학급문고 도서관
- [학생 카드] → [책 카드] 순서로 태그하면 **대여**, 책만 태그하면 **반납**
- 반납 후 별점·한 줄 평 기록 → 우리 반 **독서 온도계**가 올라간다 (목표 100권)
- 독서왕 랭킹 · 개인 독서기록장 · AI 책 소개와 독후활동 제안

## 4️⃣ 체육 기록 (셔틀런 · 서킷)
- 셔틀런: 왕복할 때마다 카드 태그 → 자동 카운트, 최고기록 갱신 시 🎉
- 서킷: [학생] → [종목 스테이션] 태그로 시작/종료, 시간 자동 기록
- 개인 성장 그래프 + AI의 격려 피드백 ("기록이 줄어도 도전을 칭찬!")

## 5️⃣ 지구 살리기 포인트
- 분리수거·급식 남기지 않기·전기 아끼기 → 포인트 적립
- 교사 PIN으로만 증감 가능 (5회 오입력 시 30초 잠금)
- AI가 "네 실천이 지구에 이런 도움을 줬어!" 눈높이 칭찬

## 6️⃣ 외부 데이터 연동
- **NEIS**: 급식 식단(알레르기 표시) + 학사일정(방학·시험)
- **공공데이터포털**: 공휴일 · 미세먼지 · 기상청 실황 → 야외활동 가능 여부 자동 판단
- **Google Sheets**: 출석·주간 점수 자동 동기화

## 7️⃣ 기록 관리
- 주간 점수표(학생×날짜), 주말·공휴일·휴업일은 결석에서 자동 제외
- 출석·감정·포인트·독서·체육 기록 **엑셀(CSV) 내보내기**
- DB 원클릭 백업, 항목별 초기화

---

## 🔒 보안 (하단 배너용)
- API 키는 **AES-256-GCM 암호화** 저장, 화면에는 가린 값(****)만 표시
- 교사 PIN 무차별 대입 방지(잠금), CSV 수식 주입 차단
- 데이터는 전부 **교실 PC 안에만** 저장 (로컬 SQLite)

## 📊 숫자로 보는 시스템 (아이콘 통계용)
- **1장** — 학생당 필요한 카드
- **5가지 모드** — 출석 · 도서대여 · 셔틀런 · 서킷 · 카드조회
- **6가지 감정** — 매일 아침 마음 체크
- **4종 AI 피드백** — 감정 · 독서 · 포인트 · 운동
- **0원 서버비** — 교실 PC에서 바로 실행

## 🔁 흐름도 텍스트 (화살표 다이어그램용)
카드 태그 → 학생 인식 → 출석+점수 기록 → 감정 선택 → AI 응원 메시지 → 대시보드·시트 실시간 반영
