## 1. 프로젝트 개요 및 리브랜딩 배경

### 1) 프로젝트 기획 의도
- 기존 **'NFC 학생 출석 프로그램'**은 초등학교 교실에서 NFC 카드를 태그해 등교 출결 및 지각을 체크하는 단일 목적의 도구로 출발하였습니다.
- 그러나 현장 교육의 다변화와 **2022 개정 교육과정(실과·체육·사회·과학·도덕)** 도입, 그리고 **지능형 과학실(Intelligent Science Lab)** 인프라 확산에 따라 단순 출석을 넘어 **학급 생활·건강 체육·창의 융합 과학 탐구·학급 자치 화폐**를 하나로 아우르는 통합 플랫폼의 필요성이 대두되었습니다.

### 2) 브랜드 리뉴얼
- **신규 공식 명칭**: **『NFC 에듀태그 (NFC EduTag)』**
- **부제**: 스마트 학급 & 지능형 과학실 올인원 솔루션
- **핵심 슬로건**: *"카드 한 장으로 열어가는 스마트 학급 & 지능형 과학실 하루"*

## 3. 주요 기능별 구현 및 아키텍처 상세

### 1) 시스템 구조도 (System Architecture)
```
[NFC 리더기 / HID 키보드] ──(Serial/USB)──┐
                                          ▼
[클라이언트 UI (HTML/CSS/JS)] ◄──(SSE/REST)──► [Node.js 서버 (Express / SQLite)]
        │                                                  │
        ├─ 🔬 지능형 과학실 패스포트 & 교구 안전             ├─ DB (students, attendance, science_*)
        ├─ 📡 SciBit (kfcman.link/scibit) 마이크로비트     ├─ AI 엔진 (Upstage Solar Pro/Mini)
        ├─ 🤖 SciBot (kfcman.link/scibot) 햄스터로봇       ├─ 공공데이터 (기상청/한국환경공단)
        └─ 🔤 가독성 극대화 진한 굴림체 (Gulim Bold)        └─ 100% 로컬 오프라인 데이터 보관
```

### 2) 데이터베이스 스키마 확장 (`src/db.mjs`)
- **`science_stations`**: 탐구 스테이션 정보(이름, 구역, 미션 설명, NFC 카드 UID)
- **`science_records`**: 학생별 스테이션 탐구 완료 타임스탬프 및 횟수
- **`science_tools`**: 과학 교구 및 화학 시약 관리(카테고리, 보관 위치, MSDS 안전 수칙)
- **`science_tool_loans`**: NFC 기반 교구 대여 및 반납 기록

### 3) 태그 라우팅 및 상태 머신 (`src/server.mjs`)
- `mode === 'science'` 시 **2단계 시퀀스 태깅**:
  1. 학생 카드를 먼저 태그하면 20초간 대기 상태(`pendingScience`) 진입
  2. 다음으로 탐구 스테이션 카드를 대면 **탐구 완료 스탬프 발급**, 교구 카드를 대면 **원터치 대여/반납 처리**
  3. 실시간 Server-Sent Events(SSE)로 프론트엔드 화면에 축하 배너 및 스탬프 애니메이션 브로드캐스트

## 5. UI/UX 디자인 및 가독성 개선 히스토리

### 1) 표준 폰트 적용: 진한 굴림체 (Gulim Ultra-Bold)
- **개선 배경**: 학교 교실의 TV, 전자칠판, 모니터에서 멀리서도 텍스트가 뭉개짐 없이 선명하게 읽히도록 직관적 가독성 개선 요청.
- **적용 기술 (`public/style.css`)**:
  - 폰트 패밀리: `'Gulim', '굴림', 'Dotum', '돋움', AppleGothic, sans-serif`
  - 폰트 굵기: `font-weight: 900`
  - 텍스트 스트로크: `-webkit-text-stroke: 0.3px currentColor` (획의 두께와 대비 강화)
  - 텍스트 컬러: 순수 딥 블랙(`--ink: #000000;`) 및 고대비 회색 토큰 적용

### 2) 공식 인포그래픽 포스터 디자인
- **적용 이미지**: `public/infographic.jpg`
- **디자인 스타일**: 3D 아이소메트릭 & 픽사풍 스마트 교실/과학실 일러스트
- **표시 영역**: 홈 화면 상단 와이드 배너 및 클릭 시 전체 화면 라이트박스 팝업

## 6. 트러블슈팅 및 버그 픽스 기록

### ⚠️ 이슈 1: 초기화면에서 다른 탭으로 화면 전환이 되지 않는 현상
- **원인 분석**:
  - `public/app.js` 내 체력 성장 그래프 함수(`loadGrowth`)의 닫는 중괄호(`}`)가 코드 교체 중 누락되어 자바스크립트 전체에 `SyntaxError: Unexpected end of input` 발생.
  - 이로 인해 스크립트 실행이 중단되어 탭 클릭 이벤트 리스너가 등록되지 못함.
- **조치 내용**:
  - `loadGrowth` 함수의 닫는 중괄호를 올바르게 수복하고, `node -c public/app.js` 문법 검사기를 통해 문법 무결성 100% 검증 완료.

### ⚠️ 이슈 2: 폰트 가독성 및 굵기 이슈
- **조치 내용**: 단순 CSS `font-weight: bold`를 넘어 `-webkit-text-stroke` 외곽선 보정과 텍스트 색상 토큰을 `#000000`으로 끌어올려 전자칠판 환경에서도 최상의 시인성 확보.

## 7. 빌드, 패키징 및 배포 워크플로 (Build & Deploy Guide)

### 1) 빌드 및 배포 자동화 명령어
```bash
# 1. 의존성 패키지 설치
npm install

# 2. 로고 SVG를 기반으로 다중 해상도 아이콘 및 PWA 아이콘 생성
npm run icon
# -> build/icon.ico, build/icon.png, public/icons/icon-192.png, public/icons/icon-512.png 생성

# 3. 로컬 데스크톱 프로그램 실행
npm start

# 4. 배포용 독립 실행 파일 (.exe) 빌드
npm run dist
# -> dist/NFC에듀태그-1.12.0-설치.exe (윈도우 설치형)
# -> dist/NFC에듀태그-1.12.0-portable.exe (무설치 포터블)
```

### 2) 배포 파일 특징
- **완전 독립 실행형**: Node.js가 설치되지 않은 학교 PC나 교사용 노트북에서도 더블 클릭만으로 즉시 구동됩니다.
- **데이터 영구 보존**: 배포 파일을 업데이트하거나 재설치해도 기존 학생 정보, 출석, 대여, 포인트 및 과학실 데이터는 `%AppData%\nfc-attendance\attendance.db`에 안전하게 보존됩니다.

## 8. 향후 발전 로드맵

1. **지능형 과학실 MBL 센서 웹 시리얼(Web Serial API) 직접 연동**: 브라우저에서 마이크로비트 USB 케이블을 꽂아 원터치로 실시간 데이터를 스트리밍하는 기능 고도화.
2. **AI 과학 탐구 보고서 자동 생성**: 학생이 수행한 스테이션 미션과 MBL 센서 측정값을 취합하여 Upstage Solar AI가 맞춤형 실험 보고서 피드백을 작성해주는 기능 확장.
3. **PWA 태블릿 오프라인 모드 강화**: 교실 PC 외에도 과학실 학생용 태블릿에서 NFC 또는 QR로 탐구 패스포트를 함께 확인할 수 있는 다중 기기 뷰어 제공.
